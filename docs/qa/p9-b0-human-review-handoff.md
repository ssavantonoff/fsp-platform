## Что заполнить

Для каждой из 38 пар сохранить исходные `need_id` / `candidate_id` и заполнить:

- `reviewer_grade`: целое 0–3 (низкая / частичная / хорошая / очень хорошая релевантность).
- `reviewer_rationale`: короткое объяснение по доступным профессиональным фактам.
- `reviewer_uncertainty`: отсутствующие данные, неоднозначность и ограничения.

При недостатке информации grade можно оставить пустым с объяснением.

не создавать обязательный полный порядок и не использовать AI/скрипт для оценивания.
