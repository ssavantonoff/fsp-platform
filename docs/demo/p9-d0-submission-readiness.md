## 1. Практическая рекомендация до дедлайна

Основной пакет — **B: видео + C: инструкция локального запуска**, с **D: санкционированным
доступом к приватному GitHub** для тех экспертов, которым требуется запуск/изучение кода.
Савелий принимает и выполняет решения об access и конкурсной публикации отдельно.

Это выполнимее до 11 октября, чем новое публичное развёртывание без подготовленного домена,
HTTPS, SMTP и проверки внешнего доступа. Однако видео не гарантирует выполнение всех
требований формы конкурса. Капитану нужно сверить обязательные поля в личном кабинете:
если требуется живая публичная ссылка, пакет B+C+D сам по себе недостаточен.

Приоритет капитана:

1. Подготовить настоящий успешный результат тестирования через UI и пройти 5-минутный preflight.
2. Записать 5–7 минут по [понятному сценарию](p9-d0-demo-script.md) и проверить файл.
3. Получить готовые презентацию и технические материалы P9-C1, указать реальные контакты команды.
4. Установить разрешённый способ доступа жюри и проверить ссылки с аккаунта без прав владельца.
5. Сверить deadline/часовой пояс/формат файлов в кабинете и подать комплект до срока.

Публичное развёртывание не выполнено и не разрешено этой задачей; его возможное начало требует
отдельного разрешения Савелия. GitHub visibility/access не изменены.
